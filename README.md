# CNMI_Pharm_public

Overview

- This repository contains analysis and visualization code for plant-derived bioactive compounds. The main analysis is performed in `analysis.ipynb`, which fetches SMILES from PubChem, computes molecular properties (Lipinski rules, TPSA, QED, etc.), and saves the results used by the other scripts and notebooks.

Requirements

- Python 3.9+ recommended (3.10 tested).
- RDKit (recommended via conda: `conda install -c conda-forge rdkit`).
- Other Python packages: `pandas`, `requests`, `matplotlib`, `seaborn`, `openpyxl`, `notebook`, `nbconvert`, `papermill`.

Setup (recommended)

- Using conda (recommended for RDKit):

```bash
conda create -n cnmi_pharm python=3.10 -y
conda activate cnmi_pharm
conda install -c conda-forge rdkit -y
pip install pandas requests matplotlib seaborn openpyxl notebook nbconvert papermill
```

- Using venv (RDKit install still recommended via conda):

```powershell
python -m venv venv
venv\Scripts\activate
pip install pandas requests matplotlib seaborn openpyxl notebook nbconvert papermill
```

Notes about RDKit: RDKit is easiest to install with conda. A pip package (`rdkit-pypi`) exists but may be less reliable across platforms.

Run order (IMPORTANT — run analysis.ipynb first)

1. Interactive (recommended):
   - Start Jupyter:

     ```bash
     jupyter notebook
     ```

   - Open `analysis.ipynb` and run all cells (Kernel -> Restart & Run All).

2. Headless / automated (execute from terminal):
   - Using nbconvert:

     ```bash
     jupyter nbconvert --to notebook --execute analysis.ipynb --ExecutePreprocessor.timeout=600 --output executed_analysis.ipynb
     ```

   - Or with papermill:

     ```bash
     papermill analysis.ipynb executed_analysis.ipynb
     ```

Why run `analysis.ipynb` first

- `analysis.ipynb` loads the input Excel file (default `Lipid Lowering Herbs with SMILE.xlsx`), fetches Canonical SMILES from PubChem, computes descriptors, and writes `Bioactive_Analysis_Full.csv`. The downstream scripts and notebooks expect that CSV (and generated charts) to exist.
- If your Excel filename differs, edit the `filename = 'Lipid Lowering Herbs with SMILE.xlsx'` variable inside `analysis.ipynb` before running.
- The notebook requires internet access for PubChem queries and may take several minutes depending on dataset size.

After analysis: run other scripts/notebooks

- `draw_molecules.py` — generates molecule images/diagrams (run after `Bioactive_Analysis_Full.csv` exists):

```bash
python draw_molecules.py
```

- `visualized.ipynb` — interactive visualization; open in Jupyter or execute headless similar to `analysis.ipynb`.

Primary outputs

- `Bioactive_Analysis_Full.csv` — main results table (generated by `analysis.ipynb`).
- `Bioactive_Analysis_Charts_Fixed.png` — figure image saved by the notebook.
- `executed_analysis.ipynb` — optional executed copy when running headless.

Troubleshooting

- RDKit install issues: use conda-forge. On Windows, prefer Anaconda/Miniconda.
- If PubChem fetches fail, verify internet access or re-run later.
- If a cell times out during headless execution, increase `--ExecutePreprocessor.timeout` value.
